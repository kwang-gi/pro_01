## 🎮 게임 실행 방법

### 1단계: 파일 열기
1. **Windows 탐색기**를 열고 `C:\k3\250811_3d_p` 폴더로 이동
2. **`index.html`** 파일을 더블클릭하거나
3. **브라우저를 열고** `Ctrl+O`를 눌러서 파일 선택

### 2단계: 게임 즐기기
**키보드 조작법:**
- **W**: 기수 올리기 (Pitch Up)
- **S**: 기수 내리기 (Pitch Down)
- **A**: 좌회전 (Yaw Left)
- **D**: 우회전 (Yaw Right)
- **Q**: 좌측으로 기울이기 (Roll Left)
- **E**: 우측으로 기울이기 (Roll Right)
- **SPACE**: 추력 (Thrust)

### 3단계: 화면 정보 확인
- **좌측 빨간 패널**: 키보드 입력 상태 실시간 확인
- **우측 초록 패널**: 비행 데이터 (속도, 고도, 추력, 각도)
- **우하단 주황 패널**: 조작법 안내
