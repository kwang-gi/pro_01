# 3D 비행 시뮬레이터 프로젝트 계획서

## 📋 프로젝트 개요
- **프로젝트명**: 3D 비행 시뮬레이터
- **생성일**: 2025-08-11
- **개발자**: 개발 입문자
- **목표**: 웹 브라우저에서 실행 가능한 3D 비행 시뮬레이터 구현

## 🛠 기술 스택

### 1. 프론트엔드 기술
- **HTML5**: 웹 페이지 구조
- **CSS3**: 스타일링 및 UI 디자인
- **JavaScript ES6+**: 게임 로직 및 인터랙션
- **Three.js**: 3D 그래픽 렌더링 라이브러리

### 2. 3D 그래픽 기술
- **WebGL**: 하드웨어 가속 3D 그래픽
- **PerspectiveCamera**: 3D 시점 카메라
- **Mesh 및 Geometry**: 3D 오브젝트 생성
- **Material 및 Lighting**: 재질과 조명 효과

## 🎯 핵심 기능 명세

### 1. 비행 제어
- **피치(Pitch)**: 상하 기울기 제어
- **요(Yaw)**: 좌우 회전 제어  
- **롤(Roll)**: 기체 회전 제어
- **스로틀**: 엔진 출력 조절

### 2. 물리 시뮬레이션
- **중력**: 지구 중력 9.8m/s²
- **공기 저항**: 속도에 비례하는 항력
- **양력**: 날개 각도와 속도에 따른 상승력
- **관성**: 질량과 가속도 기반 움직임

### 3. 환경 요소
- **지형**: 산, 강, 도시 등 다양한 지형
- **날씨**: 맑음, 흐림, 비, 안개
- **시간**: 낮/밤 사이클
- **바람**: 방향과 강도가 있는 바람 시스템

## 🚀 실행 방법

1. **프로젝트 폴더 열기**
   ```bash
   cd C:\k3\250811_3d_p
   ```

2. **index.html 파일 브라우저에서 열기**
   - 더블클릭으로 실행
   - 또는 브라우저 주소창에 파일 경로 입력

3. **조작법**
   - W/S: 피치 제어 (상승/하강)
   - A/D: 요 제어 (좌회전/우회전)
   - Q/E: 롤 제어 (좌경사/우경사)
   - 스페이스바: 엔진 추력 증가
   - Shift: 엔진 추력 감소
