# settlement 모듈

예치금·주선비·성사비 원장(ledger) 처리 블럭. 성사 시 총 성사비(10) 기록과 주선자 분배(기본 50%),
신고 확정 시 몰수 처리, 매칭 이력 유무에 따른 즉시환불/환불대기 분기를 담당합니다.

## 교체 가이드
현재는 SQLite 테이블(`ledger_accounts`, `settlements`, `deposit_requests`)로 직접 원장을 관리합니다.
실제 회계/정산 시스템과 연동하려면 이 모듈의 함수 시그니처를 유지한 채 내부 구현만
외부 API 호출로 바꾸면 나머지 코드(app/api, admin 화면)는 수정할 필요가 없습니다.
