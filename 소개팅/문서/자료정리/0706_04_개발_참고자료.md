## 1. 코드팩토리 튜토리얼 핵심 (클로드 코드로 소개팅 앱 만들기)

### 설치·모드
- 설치: curl 명령어 터미널 설치 권장, `claude` 로 실행 (+ dangerously-skip-permissions 플래그)
- **Shift+Tab 4모드**: 기본(매번 허가) / Accept Edits(파일 수정 자유) / **Plan(작업 전 계획, 시작은 항상 이걸로 권장)** / Bypass Permissions(전권)
- 사고 수준 옵션: low/medium/high/**max** — max로 오래·깊게 생각 유도

### 추천 기술 스택 (초보 기준)
- 프론트: **React Native** (디버깅 자동화에 유리)
- 백엔드/DB: **Supabase** (서버리스 API 자체 제공, Free 플랜, 서울 리전) — 숙련자는 Convex
- 실시간 채팅: WebSocket
- 인프라 비용 월 100만 원 넘기 전까진 Supabase로 충분

### MCP 자동화 워크플로우
1. Supabase 프로젝트 생성 (수동) → DB 스키마 적용은 MCP로 자동
2. MCP 등록 후 클로드 코드 재시작 (`claude -c` 로 대화 복구), `/mcp` 로 확인·인증
3. 수동 작업: 스토리지 버킷 `profile-photos` 생성(Public) + **RLS 정책 4개** (authenticated_upload=INSERT / public_read=SELECT / owner_delete=DELETE / owner_update=UPDATE) + 이메일 확인 토글 Off(테스트용)
4. 디버깅 자동화: Expo 토큰 발급 → 디버깅 MCP 등록 → "MCP로 전부 검증하고 될 때까지 반복 개선, 수동 작업은 인스트럭션 달라" 루프
- 교훈: **AI가 직접 디버깅할 수 있는 프레임워크 선택이 절대적으로 유리**

### 프롬프팅 팁
- Typeless(음성→정리된 프롬프트, 한국어→영어 자동 번역) — 영어 프롬프트가 토큰 절약
- 요구사항은 번호 매겨 구조화하면 응답 품질 상승
- 모르면 사람 대신 AI에게 스텝바이스텝으로 물어보는 습관
