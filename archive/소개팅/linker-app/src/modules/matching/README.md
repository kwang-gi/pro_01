# matching 모듈 (핵심 도메인, 모의 아님)

지인 등록 -> 소개 제안 -> 수락(주선비 차감) -> 만남 1~3회 기록 -> 3회 완료 시 성사 판정까지의
핵심 비즈니스 로직입니다. 성비 룰(남자 주선자는 여자 지인만), 동일 지인 월 3회 쿨타임,
성사율 계산이 여기 있습니다.

## 교체 가이드
이 모듈은 모의 처리 대상이 아니라 실제 사업 규칙이므로 통째로 교체할 일은 없지만,
`rules.ts`의 상수(`MEETING_TO_MATCH`, `MONTHLY_COOLTIME_LIMIT`, 금액 등)를 바꾸면
정책 변경(예: 만남 횟수, 쿨타임 횟수, 금액)에 바로 대응 가능합니다.
