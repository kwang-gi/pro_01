## 1. 소개팅 앱(데이팅 앱) 페인포인트

- **극심한 성비 불균형**: 남녀 8:2~9:1. 여성은 '좋아요' 폭탄 피로(여왕벌 현상), 남성은 돈 써도 매칭 안 되는 박탈감. 여성에게만 무료 재화 주는 성차별 정책 반발
- **결과 보장 없는 과금**: 프로필 열람·호감·채팅방 개설 등 단계마다 결제. 읽씹/안읽씹이어도 환불 불가
- **가짜 계정(알바)·유령 회원**: 운영사 테크랩스가 타인 사진 도용 **가짜 여성 계정 약 270개** 직접 운영, 남성 결제 유도 → **피해 남성 2,200여 명, 약 23억 원**
- **낮은 유지율**: 30일 리텐션 **2%** 수준 → 신규 유입 마케팅비 부담. 틴더·범블 성장 정체, 앱 피로도 최고조
- **범죄 노출**: 로맨스 스캠(평균 8일 내 금전 갈취), 사이비 포교, 기혼자 위장, 신원 검증 부실
- **보안 사고**: 여성 전용 앱 'Tea' — 신분증 셀카 포함 이미지 **7만 2천 장 유출**

## 2. 결혼정보회사(결정사) 페인포인트

- **미끼 매물·의무 방어전**: 가입 전 고스펙 프로필로 유인 → 가입 후 횟수 차감용 억지 매칭
- **고액 선불 + 환불 거부**: 수백만~수천만 원 선불. 1년간 1회도 주선 안 하고 "계약기간 경과" 환불 거부. 공정위 규정 회피용 **'기본 횟수/서비스 횟수' 쪼개기 계약서**
- **비인간적 등급제**: 스펙으로 사람 재단 → 자존감 상처. 서류 스펙은 봐도 매너·인성은 미검증
- **매니저 실적 압박·가스라이팅**: 안 맞는 상대 강요, 실패 시 회원 탓
- **혼탁한 업계**: '업계 1위' 문구 두고 업체 간 소송·가처분 반복

## 3. 프리미엄·인증 기반 서비스의 함정

- **골드스푼**: 해킹으로 회원 **14만 명 경제력 인증자료 유출** + 가상화폐 **25억 협박**
- **전과 10범 사기꾼**이 자산가 위장 가입 → 운영자 '인증 책임' 리스크
- **소울매처**(월 1명 엄선 구독): 만족도 높지만 유저 6~7%만 결제 가능 → 확장 한계

## 4. 로맨스 스캠 (MBC 히든아이 EP.14 정리)

### 3단계 수법
1. **약점 파악** — SNS로 외로움·상황 사전 조사
2. **신뢰 형성** — 약 2주(길게는 2~7년), 호감 표현+선물 공세 ("공사 사이즈 재기")
3. **투자 권유·편취** — 수술비·상속세·로비자금 등 긴급 상황 연출 → 잠적

### 특징
- 전문직 사칭 (의사·파일럿·갤러리 관장) + 유니폼·제복으로 신뢰 연출
- 동시다발 문어발 사기 (한 명이 5명 동시 진행), 다른 피해자 돈으로 돌려막기
- 남녀노소 무차별 — 82세 할머니 15억 피해 사례
- **피해액 급증: 2024년 2~6월에만 450억+ (직전 5년 합계 138억의 3배)**

### 대표 사례
- 갤러리 관장 사칭 여성: 대기업 50대 남성에게 2년간 11억 편취 (퇴직금 3.8억 포함) → 피해자 극단 선택
- 파일럿 사칭 남성: 피해자 4명 약 5억, 징역 5년 + 민사 배상

### 대처
- 즉시 은행 지급정지 신청 (골든타임) + 경찰청 사이버범죄 신고시스템(ECRM) 신고 + 증거 보존

## 5. 일본 소개팅 앱 '바가지 술집' 피해 (KBS 글로벌K, 2024.12.03)

- 소개팅 앱에서 만난 상대가 특정 술집으로 유인 → 바가지 요금. 외부 업체와 결탁한 조직적 사기
- Linker 시사점: 등기 인증 + 지인 보증으로 외부 결탁 사기 원천 차단 논리의 근거 영상

## 6. 실사용자 목소리 (레딧 r/dating, 31세 남성)

- 10년 앱 사용 → "같은 사람만 계속 보임, 매치 안 됨"
- **선택지 과잉 → 사람들이 너무 쉽게 포기** / 오히려 더 외로워짐
- 앱 끊고 오프라인(볼링 리그, 카페)으로 전환 결심 → 진지한 관계 갈망 확인

## 7. 종합 — 소비자 핵심 니즈 4가지 (Linker가 공략할 지점)

1. **"돈 냈으면 확실하게 만나게 해달라"** → 결과(성사) 기반 과금·에스크로
2. **"알바·유령 말고 신원 확실한 사람"** → 지인 소개 + 등기 인증
3. **"수백만 원 선불은 부담, 가벼운 앱은 싫다"** → 합리적 예치금 구조
4. **"서류 등급 말고 실제 괜찮은 사람(매너)"** → 지인 보증 + 매너 등급제
