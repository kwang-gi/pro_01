# Linker 사업 기획 핵심 정리 (2026-07-06)

> 출처: 소개팅.mht 내 Gemini 대화 전문 (2026-04-13) + repo 18_대표_지시사항_집대성.md, 01_PRD(v1.6)

## 1. 서비스 컨셉

- **지인 소개 기반 리워드 매칭 웹 플랫폼** (가칭: Linker)
- 누구나 자기 주위의 지인을 소개팅 희망자에게 소개 → 주선자(리셀러)로 등록, 성사 시 수수료 수익
- **커플 성사 기준: 첫 소개일로부터 3번 만나면 성사 간주** (기준은 5회·7회·여행 등으로 프리미엄 세팅 가능)
- 웹(반응형) 우선. 웹스토어 미등록 — 홈페이지에서 텔레그램처럼 직접 다운로드하는 설치형 클라이언트(Tauri) 병행
- 결혼정보회사가 아님: 기본 만남 코스(차·식사)까지만 제공, 애프터는 당사자 몫

## 2. 요금·정산 구조

| 항목 | 금액(단위: 상대값) | 비고 |
|---|---|---|
| 최초 결제 | 예치금 5 + 1회차 주선비 1 = **6 선입금** | "진정성 예치금" — 가벼운 유저 차단 |
| 소개마다 | 주선비 1~4 선불 | 본인 희망 조건에 따라 |
| 성사 시 | 잔금 5 추가 → **총 성사비 10** | 에스크로 흐름 |
| 실패 시 | 주선자 몫(1) 제외 환불 | 매칭 전 = 즉시 환불, 매칭 후 = 유예+주선자 확인 후 |

- 성사 수수료 실제 구상: **70만~120만 원 (하이엔드/프라이빗 헤드헌팅급)** → "지인 허들" 해소 장치
- 수익 배분: 주선비·성사비 모두 플랫폼-주선자 사전 약정 비율로 분배
- **현금(가상계좌) 결제 위주**, 카드 최소화. 환불은 입금한 본인 명의 계좌로만 (자금세탁 방지)
- 정산: 건별 아님 — **최소 금액(예: 10만 원) 이상 또는 일정 주기 묶음 정산**
- 1회차 만남 주선비는 **환불 규정 없음 명시** ("마음에 안 듦"은 환불 사유 아님)

## 3. 성비 불균형 대응 룰

- 남초 시장(8:2) 전제
- **남자는 여자만 소개 가능** (남자가 남자 소개 금지)
- **여자는 남자·여자 모두 소개 가능**
- 인기남 예외 규칙: 남성 소개도 수수료 수취 가능 (객관 지표 필요 — 전문직 자격증, 원천징수 등). 단, 성사되면 일정 기간 재소개 불가(쿨타임)라 자연 소멸

## 4. 신원 인증 — 등기 우편 인증 (PAV)

- 여성: 문자 인증 / **남성·주선자: 등기 인증** — 실시간 이름 확인 후 실거주지로 등기 발송, 등기 안의 안내대로 입력해야 가입 승인
- 개인정보 최소 수집: 몇 년생·사는 곳·직업 정도의 불특정 정보만, 상세 신상 불요
- 효과: ① 주선자 안심 보장("플랫폼이 그 사람 집 주소를 안다") ② 가해 의도자에게 심리적 압박 ③ 장난성 가입 99% 차단
- 지인 프로필 등록 시 **본인 동의 알림톡 필수** (무단 등록 방지, 초상권/개인정보법 대응)

## 5. 무관용 원칙 (예치금 100% 즉시 몰수 — 4대 조항)

한 마디라도 나오면 몰수, 변명 불가:
1. **데이트 폭력·언어 폭력** (욕설, 위협, 모멸)
2. **사이비 종교·포교** (심리 공부 빙자 포함)
3. **사업·동업 제안**
4. **돈 얘기** (대출, 코인, 주식, 투자 권유)

+ **주선자 연대 책임**: 가해자를 데려온 주선자의 예치금·수익금도 통째 몰수
+ **즉시 가동 시스템**: 피해 발생 → 피해자 즉시 환불 + 전체 공지(경각심) 
+ 데이트 규약: 남성 — 비싼 술집 유인(바가지) 금지 / 여성 — 쇼핑 결제 전가 금지 / 첫 만남 비용 상한선 플랫폼이 제시

## 6. 어뷰징 방어 로직 (5대 시나리오 대응)

| 시나리오 | 대응 |
|---|---|
| 주선자-당사자 뒷거래 (수수료 회피 담합) | 성사율 모니터링 알고리즘 (소개 많은데 성사 0% → 의심·패널티). 단, 수수료가 합리적이고 실패 신고 시 계속 다른 소개가 들어와 실제 커플에겐 오히려 귀찮음 → 자연 심리 방어막 |
| 매력 지인 알바 (1회차 주선비 헌터) | 소개받는 지인 단위 횟수 제한 (예: 동일 인물 월 3회) |
| 무단 프로필 등록 + 고의 파투 | 동의 알림톡 필수 |
| 자금세탁 (입금 후 전액 환불 반복) | 본인 명의 계좌 환불 원칙 + 이상 거래 탐지 |
| 별점 테러 (경쟁사·악성 유저) | 연속 최하점 부여자 Black/Red 분류, 평점 즉시 반영 아닌 '보류' 후 관리자 검토 |

## 7. 문화·에티켓 시스템

- **김비서 독설 애니메이션**: 긴 약관 대신 만남 확정 직전 팝업 멘트. "여기 전지현/아이유 안 나온다. 눈높이 바닥에 처박고 나와라" / "박보검 찾으려면 연예기획사 가라" — 불순 의도자만 뜨끔할 멘트 포함
- **이별 에티켓 프로토콜**: 마음에 안 들어도 집 앞 배웅 + 정중한 거절 메시지 ("오늘 반가웠고, 제 스타일은 아니지만 좋은 사람 만나세요"). 잠수·읽씹 금지. 정중 거절 툴 제공, 매너를 등급·정산율에 연동
- 핵심 가치: **"상대도 미용실 가고 시간 내서 나왔다 — 주선자 얼굴 봐서라도 최소한의 예의"**
- **투명 경영 선언**: 시스템 오류·한계 숨기지 않고 공개, 지적 환영, 함께 고침

## 8. 운영·마케팅 전략

- **소수 정예 주선자 핀셋 모집** (린 스타트업) — 전국 확장 불필요, 몇 명의 주선자 + 그 주변 지인이면 충분. 반응 보며 점진 확대
- 마케팅 피치: "돈 벌 사람 손? → 주위 적적한 사람 애인 만들어 주면 돼. 다단계 아님" / "아는 사람 없는데요? → 집으로 가세요"
- 사용자·주선자 **등급제** (우수 주선자 수수료 우대, 사고 주선자 도태), 관리자 대시보드(등급 조정·강제 집행)
- 법적 대비: 중개업 사업자 등록. 세무 문제는 확장 시점에 처리
- 사용자 본인이 마케팅 경력 김 → 초기 유저 확보 자신 있음

## 9. 미결/추후 논의

- 웹 vs 앱 역할 분담 (readme: 웹 = 사용설명·편의·앱 다운로드·버전관리 / **앱 부분은 readme 미완성**)
- 인기남 판별 객관 지표 확정
