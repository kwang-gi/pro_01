# 지렁이 게임 사용 설명서 (User Manual)

## 1. 개요
이 문서는 "지렁이 게임"의 설치 및 실행 방법, 그리고 게임 조작법을 안내합니다.

## 2. 요구 사양
- Python 3.x
- Pygame 라이브러리

## 3. 설치 방법
게임 실행을 위해서는 `Pygame` 라이브러리가 필요합니다. 다음 명령어를 사용하여 설치할 수 있습니다.

```bash
pip install pygame
```

## 4. 게임 실행 방법
1.  터미널(명령 프롬프트)을 엽니다.
2.  `cd` 명령어를 사용하여 이 파일이 있는 `pro_01/0811test` 폴더로 이동합니다.
3.  다음 명령어를 입력하여 게임을 실행합니다.

```bash
python snake_game.py
```

## 5. 게임 조작법
- **↑ (위쪽 화살표 키):** 뱀을 위로 이동
- **↓ (아래쪽 화살표 키):** 뱀을 아래로 이동
- **← (왼쪽 화살표 키):** 뱀을 왼쪽으로 이동
- **→ (오른쪽 화살표 키):** 뱀을 오른쪽으로 이동

## 6. 게임 규칙
- 초록색 먹이를 먹으면 뱀의 길이가 길어지고 점수가 오릅니다.
- 벽에 부딪히거나 자기 자신의 몸에 부딪히면 게임이 종료됩니다.
- 게임 오버 화면에서 **'C' 키**를 누르면 다시 시작하고, **'Q' 키**를 누르면 게임을 종료합니다.
