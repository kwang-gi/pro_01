# 지렁이 게임 개발 진행도

## 1. 게임 필요 스펙 (요구사항)

*   **게임 명칭:** 지렁이 게임 (Snake Game)
*   **개발 환경:** Python, Pygame 라이브러리
*   **게임 화면:**
    *   지정된 크기의 격자형 게임 보드
    *   게임 보드 내에 지렁이와 먹이가 표시됨
    *   현재 점수가 화면에 표시됨
*   **게임 요소:**
    *   **지렁이:**
        *   사용자가 방향키로 조종할 수 있음
        *   초기에는 짧은 길이로 시작
        *   먹이를 먹으면 길이가 1칸씩 늘어남
    *   **먹이:**
        *   게임 보드 내 임의의 위치에 생성됨
        *   지렁이가 먹으면 사라지고 새로운 위치에 다시 생성됨
*   **게임 규칙:**
    *   지렁이는 계속해서 앞으로 이동함
    *   사용자는 방향키(상, 하, 좌, 우)로 지렁이의 진행 방향을 바꿀 수 있음
    *   지렁이가 벽에 부딪히면 게임 오버
    *   지렁이가 자기 자신의 몸에 부딪히면 게임 오버
*   **점수:**
    *   먹이를 하나 먹을 때마다 점수가 1점씩 증가
*   **게임 종료:**
    *   게임 오버 시, 최종 점수와 함께 "게임 오버" 메시지를 화면에 표시

## 4. 어떻게 테스트 되는지 알려줘 (테스트 계획)

*   **단위 테스트 (Unit Test):**
    *   **수동 단위 테스트:** 각 기능 구현 직후, 해당 기능이 의도대로 동작하는지 즉시 실행하여 확인.
        *   **입력 테스트:** 방향키 입력 시 지렁이의 방향이 올바르게 바뀌는가?
        *   **성장 테스트:** 먹이를 먹었을 때 지렁이의 길이가 실제로 늘어나는가?
        *   **점수 테스트:** 먹이를 먹었을 때 점수가 정확히 오르는가?
*   **통합 테스트 (Integration Test):**
    *   **게임 플레이 테스트:** 초기 단계부터 게임을 직접 플레이하면서 전체적인 흐름과 기능들의 상호작용을 테스트.
        *   **시나리오 1 (기본 플레이):** 벽이나 자기 몸에 부딪히지 않고 5개의 먹이를 먹을 수 있는가?
        *   **시나리오 2 (벽 충돌):** 게임 보드 경계에 부딪혔을 때 게임 오버 처리가 정상적으로 되는가?
        *   **시나리오 3 (몸 충돌):** 지렁이의 길이가 4 이상일 때, 자기 몸에 부딪히면 게임 오버가 되는가?
*   **테스트 실행 방법:**
    1.  터미널 또는 명령 프롬프트를 연다.
    2.  `pygame` 라이브러리가 설치되어 있는지 확인한다 (`pip show pygame`). 설치되어 있지 않으면 `pip install pygame` 명령어로 설치한다.
    3.  `cd pro_01/0811test` 명령어로 프로젝트 폴더로 이동한다.
    4.  `python snake_game.py` 명령어를 입력하여 게임을 실행한다.
    5.  게임 창이 나타나면, 위 테스트 시나리오에 따라 직접 플레이하며 결과를 확인한다.
    6.  오류 발생 시, 터미널에 출력되는 에러 메시지를 확인하여 디버깅한다.
